# AI Study Copilot

Вставляете конспект — получаете **краткий пересказ**, **карточки** и **тест**.
Ошибки из теста сохраняются в «Слабые места».

## Запуск (2 команды)

```bash
npm run install:all   # один раз: ставит всё
npm run dev           # сервер + сайт, открыть http://localhost:5173
```

Работает сразу, **без API-ключа**.

## Как работает ИИ

Сервер сам выбирает первый доступный движок (файл `server/ai.js`):

| № | Движок | Нужно | Качество |
|---|--------|-------|----------|
| 1 | **cloud** — облачный ИИ (OpenAI или совместимый) | ключ `LLM_API_KEY` | лучшее |
| 2 | **ollama** — нейросеть на вашем компьютере | установить [Ollama](https://ollama.com), `ollama pull llama3.2` | хорошее, бесплатно, без ключа |
| 3 | **offline** — встроенный алгоритм | ничего | простое: важные предложения + тест «вставь слово» |

Если выше стоящий движок недоступен или ответил ошибкой — берётся следующий,
поэтому приложение не «ломается» без ключа. На экране результата написано, какой движок сработал.

Чтобы включить cloud, скопируйте `server/.env.example` в `server/.env` и раскомментируйте строки.

## Структура

```
server/
  index.js     HTTP: принимает текст, проверяет длину, отдаёт результат
  ai.js        движки cloud / ollama, промпт, проверка ответа ИИ
  offline.js   встроенный движок без нейросети
client/src/
  App.jsx      состояние и переключение экранов
  screens/     по файлу на экран: Home, Result, Quiz, WeakSpots
  api.js       запрос к серверу
  weakSpots.js сохранение ошибок в браузере (localStorage)
  styles.css   все стили
```
